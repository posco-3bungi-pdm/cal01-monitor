# Menu mascot

User-supplied Poseokho PNGs, copied without bitmap changes on 2026-10-24:

- `poseokho-greeting.png`: clipboard image 672f01c5-f2d3-41f8-8b4b-c03476fdf0f3 (greeting pose).
- `poseokho-cheer.png`: clipboard image 7475f5e3-cf26-4e8f-8ce4-28867bddfb68 (celebration pose).

Original aspect ratios are retained with object-fit. The greeting image stays on screen, with slow breathing and weight shifts anchored at the feet. Opening the menu or clicking the character adds a small, smoothly eased nod; repeated clicks continue from the current pose. These are whole-image transforms, not articulated character animation. The celebration PNG is retained as an available asset.

Copy is encouragement, never a computed equipment status or assertion that operation is complete/safe. Automatic motion and message changes pause when the menu is closed, when paused by the user, or when reduced motion is enabled. Manual message changes still work while paused, without starting a nod.
