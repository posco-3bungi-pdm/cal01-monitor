# 실시간 누적 그래프와 Z-score

실시간 기본 그래프는 **현재 코일(LOT)의 첫 관측 시각**을 왼쪽 축에 고정하고 최신 도착 시각까지 누적한다. 같은 LOT의 수신이 계속되어도 시작 시각이 이동하지 않으며, 새 LOT의 첫 행이 도착할 때만 새 코일의 시작 시각으로 전환한다. 날짜와 시각 축은 초까지 표시한다. 구간을 확대하거나 이전 코일을 조회한 뒤 `현재 코일 전체` 또는 `현재로`로 현재 코일의 누적 조회에 복귀한다. 앞선 코일의 이력은 이전 기록 조회를 위해 보존한다.

왼쪽 수신 카드의 `관측 시각`도 같은 코일의 `YYYY-MM-DD HH:mm:ss ~ HH:mm:ss` 범위로 표시한다. 시작은 고정하고 끝은 실제 수신한 최신 시각으로 갱신한다. 날짜를 넘으면 끝에도 날짜를 표시한다. 이전 기록을 검토할 때에도 이 범위는 실제 수신을 따라가며, 조회 중인 과거 시각은 별도로 표시한다.

3D와 짧은 구간 조회용 원자료 버퍼는 최근 1801행을 유지한다. 별도의 누적 이력은 수신할 때마다 갱신한다. 표시량이 커지면 같은 LOT의 연속된 관측을 묶되 첫값·끝값, 원자료 최솟값·최댓값, Z-score 최솟값·최댓값과 실제 시각을 보존한다. LABEL 구간과 통계 임계치 초과 구간은 별도로 보존한다. 구간 확대는 기존 원자료 조회를 이용한다.

그래프의 실시간 Z-score는 같은 LOT의 **이전 유효 원자료 30개 이상**으로 평균과 모집단 표준편차(ddof=0)를 구한다. 새 값의 `Z = (현재값 - 이전 평균) / 이전 표준편차`를 계산한 뒤 기준 통계에 새 값을 더한다. 아직 도착하지 않은 값과 CSV LABEL은 계산에 사용하지 않는다. 미래 관측이 과거 점의 Z-score를 바꾸지 않는다. 결측과 표준편차 0은 계산 대기로 표시한다.

주황 점선은 각 시점의 이전 평균 ±3σ, 붉은 음영과 점은 |Z| > 3인 시각이다. 초과 구간에는 정확한 시작·끝 시각, 최대 |Z|와 관측 수를 보존한다. 음영이나 구간 버튼을 누르면 해당 구간을 확대한다. 붉은 음영은 통계적 이탈 표시이며 설비 운전 한계값이 아니다.

기존 등록 모델과 닫힌 1분 단위 추론은 수정하지 않는다. 모델의 Z-score는 같은 LOT의 이전 완료된 1분 평균이 30개 이상 쌓이면, 그 이전 분들의 누적 평균과 표준편차를 기준으로 계산하는 별도 결과다. 그래프의 원자료별 참고 통계와 모델 알림을 구분해 표시한다. 새 수신 시작이나 자료 변경은 누적 이력과 기준 통계를 초기화한다.
