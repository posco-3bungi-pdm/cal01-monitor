# 공정 가이드와 화면 사용 튜토리얼

메뉴 상단은 `연속소둔공정` 제목과 포석호의 응원 말풍선으로 표시한다. 작업 화면 상단의 CAL01 표시는 유지한다. 캐릭터 이미지는 사용자가 제공한 인사·축하 PNG 원본을 사용한다.

포석호는 열린 메뉴에서 발 위치를 고정한 채 호흡하듯 작게 움직이고 천천히 무게중심을 옮긴다. 메뉴를 열거나 캐릭터를 누르면 부드럽게 까딱이며, 연속해서 눌러도 현재 자세에서 이어진다. 응원 문구는 9초마다 또는 캐릭터를 누를 때 바뀐다. 옆의 일시정지 버튼은 움직임과 자동 문구 전환을 멈춘다. 기기의 동작 줄이기 설정도 따른다. 멈춘 상태에서는 눌러도 문구만 바뀐다. 말풍선은 라이트 모드에서 밝은 청회색, 다크 모드에서 짙은 청회색으로 표시한다. 응원 문구는 장비의 안전 판정·운전 완료 상태와 연결하지 않는다.

## 소둔로 공정 가이드

메뉴 → **소둔로 공정 가이드**에서 다음 주제를 선택한다.

| 주제 | 내용 |
| --- | --- |
| 공정 흐름 | 소둔 목적, 강판 이동 순서, 존별 역할, 정상적인 운전 전환 |
| 운전·센서 | TC·OP·CP 의미, 단위, 반응 관계, 그래프 시각·축·통계선 |
| 이상 징후 | 정상 전환·추가 확인·보고의 구분, 원인 검토, 협업 자료, 설명용 연습 |
| 강종·품질 | 기존 제품 사전의 강종별 용도, 소둔 조건·품질 관계, LOT 추적 |
| 정비·조업 | 정기수리·돌발정비·계획정지·강종변경·재가동, 계획과 실제 이력 |
| 설비·용어 | 버너·래디언트 튜브, 위치·센서 코드, 약어와 용어 |

주제별 목차와 이전·다음으로 읽는다. 마지막 페이지의 다음 주제는 다음 범주로 이동한다. 검색창은 제목·본문·확인 항목·센서 코드·용어 정의를 검색한다. 검색 결과를 선택하면 해당 페이지가 열린다. 강종별 제품 정보는 기존 `/api/material-grades`를 조회하며 별도 강종 목록이나 운전 설정값을 만들지 않는다.

정비 판단은 실제 기록과 감지 시각을 대조한다. 날짜만 있는 계획과 실제 작업 구간, 기록 미연결과 정비 없음을 구분한다. 통계적 이탈·모델 감지·현장 고장 판정은 구분하며, 분석 모델 구현이나 경보 기준은 변경하지 않는다.

## 화면 사용 튜토리얼

메뉴 → **화면 사용 튜토리얼**로 시작한다. 다음 9단계가 실제 화면 영역을 강조한다.

1. 자료·LOT·강종·관측 시각
2. 과거 기록·실시간·검색
3. 공정 구역 선택
4. 현재 모드에 맞는 기록 이동·배속·현재 복귀
5. 설비 표현·내부·부품·코일 색상
6. 채널 그래프와 구간 확대
7. 이상 감지와 저장된 후보
8. 팀 점검 요청함
9. 메뉴의 공정 가이드와 튜토리얼 다시 시작

**이전·다음**으로 단계를 이동한다. **건너뛰기**, **종료(X)**, **Esc**는 안내를 끝낸다. 마지막의 **마치기**도 종료한다. 강조한 영역은 설명용으로 표시하며 안내 중에는 뒤쪽 버튼 조작과 요청 전송을 막는다. 키보드 Tab은 안내 버튼 사이를 이동한다.

그래프·점검 요청 단계에서는 해당 창을 자동으로 보여주고, 끝나면 시작 전 메뉴·창·설정의 열림 상태와 초점을 복원한다. LOT·조회 시각·분석 모델·수신 상태는 변경하지 않는다. 실시간 수신은 계속 진행한다. 해당 영역이 없는 자료에서는 설명과 다음 이동을 제공한다. 창 크기가 바뀌면 강조 영역과 설명 카드 위치를 다시 계산한다.
