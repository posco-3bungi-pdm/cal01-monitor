# 포석호 표정·새 코일 알림·공정 가이드

이슈 #55. 메뉴 기본 표정은 인사·엄지 하나·엄지 둘을 9초마다 무작위로 바꾸며 직전 표정은 반복하지 않는다. 포석호를 누르면 돋보기·파이팅·축하 표정 중 하나와 포스코 정신을 바탕으로 새로 쓴 응원 문구가 나온다. 표정에 따라 살펴보는 기울임, 작은 힘주기, 가벼운 축하 움직임을 사용한다. 메뉴 닫힘·일시정지·동작 줄이기에서는 자동 전환과 모션을 멈춘다. 수동 클릭은 정지 상태에서도 표정과 문구를 바꿀 수 있다.

응원 문구는 공식 인용문이나 실시간 설비 상태가 아니다. 제철보국·창의·인재육성·희생과 봉사의 의미를 바탕으로 일상적인 말로 작성하고, 도전·신뢰·실천·배려·기본과 원칙의 응원을 더했다.

새 코일 알림은 실제 수신 프레임의 LOT가 처음 등장하거나 바뀔 때만 발생한다. 과거 조회 커서는 사용하지 않는다. 같은 LOT의 매초 수신·강종 정보 갱신·메뉴 개폐로 반복하지 않는다. 자료/수신 회차가 바뀌면 추적을 초기화한다. 알림 중 다음 LOT가 들어오면 최신 알림으로 교체한다. 과거 기록 모드에서 수신된 알림을 나중에 재생하지 않는다.

운반차와 LOT·강종·수신 시각 꼬리표는 구역 선택 버튼 바로 위를 왼쪽에서 오른쪽으로 10초간 한 번 지난다. 높이는 버튼보다 6px 작고, 이미지 가로 비율은 원본을 유지한다. 영역은 클릭을 가로채지 않는다. 동작 줄이기에서는 중앙에 6.5초 표시한다.

메뉴와 공정 가이드가 차지하는 실제 가로 범위를 측정해 3D 카메라의 중심 이동에 사용한다. 전체 화면 너비의 일정 비율을 메뉴 공간으로 가정해 공정이 축소되던 동작을 수정했다.

가이드의 설비·용어에는 카본 포텐셜, 질소·수소 분위기, 노점·산소, CP 태그의 해석과 함께 확인할 기록을 추가했다. 일반 열처리 원리와 이 자료의 태그·현장 조건을 구분하며 가스 조작값을 제시하지 않는다. 참고 자료는 해당 페이지에서 열 수 있다.

강종·품질의 제품 사전은 기존 8개 강종을 선택해 용도, 필요한 품질, 공정 관측과 연결하는 관점, 함께 확인할 기록을 바로 읽는다. 참고 링크는 설명 아래에 둔다. 기존 제품 카탈로그를 근거로 일반 용도를 요약하고 기록 확인 항목은 교육용으로 작성했다. 실제 코일의 합격 여부나 운전 설정값을 추정하지 않는다.
