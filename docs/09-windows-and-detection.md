# Windows 앱에서 이상 후보 확인하기

`CAL01-Monitor-0.2.0-win-x64.exe`는 공통 서버에 접속하는 Windows 앱임. 첫 실행은 이 PC의 `http://127.0.0.1:9017`에 연결함. `CAL01 → 서버 연결 설정`에서 팀 서버의 HTTPS 주소로 바꿀 수 있음.

데이터와 요청은 서버에 저장함. exe를 다른 PC로 복사해도 데이터·비밀번호를 같이 복사하지 않음. 현재 실행 파일은 서버와 DB를 설치하는 프로그램이 아니므로 서버가 실행 중이어야 함.

## 화면에서 하는 순서

설비 3D가 화면 전체에 깔림. 채널을 누르면 설비 옆에 값과 시각이 뜨고, 그래프·이상 후보·요청함은 위에 겹쳐 열림. 패널을 닫으면 설비 전체로 돌아옴.

1. LOT와 채널을 고르고 Z-score 분석 실행.
2. 이상 후보가 있는 구역과 채널을 빨갛게 표시.
3. 후보를 누르면 해당 구간의 그래프와 기준 범위를 표시.
4. 현장 확인 요청에 같은 후보·채널·구간을 붙여 저장.
5. 현장팀이 요청을 맡고 결과 등록.
6. 모니터링팀이 결과를 확인하고 완료.

새 후보와 요청 변경은 팀 알림으로 저장하며 약 5초마다 새 기록을 가져옴. 후보의 `확인`은 알림 움직임을 멈추는 동작이며 고장 해결이나 현장 요청 완료를 뜻하지 않음.

## 이번 Z-score 기준

이 절은 **선택한 LOT의 과거 자료 분석** 기준임. 별도로 실시간 메뉴에서 CSV를 순서대로 수집하는 시연과 RandomForestClassifier 구역 예측을 제공한다. 실제 설비 수집원 연결은 아니며, 과거 LOT 전체 Z-score와 CSV 시연의 지난 값 기반 모델 판단은 구분한다. 모델 입력·기준 부족 처리 등은 [이상 탐지](04-detection.md)를 따른다.

| 항목 | 이번 구현 |
| --- | --- |
| 기준 자료 | 선택한 LOT 전체 원자료, 채널별 계산 |
| 표준편차 | `ddof=0` |
| 후보 조건 | `abs(z) > 3` |
| 기존 라벨·제외 표시 | 계산에 사용하지 않고 원문 유지 |
| 기본 최소 관측 수 | 채널당 30개 |
| 기본 허용 공백 | 60초. 정상값·결측 또는 긴 공백에서 구간 종료 |
| 기준 부족 | 표본 부족·상수 채널은 점수 계산하지 않고 이유 표시 |
| 중복 실행 | 같은 파일·LOT·채널·설정이면 기존 결과 재사용 |

기존 `03_Z-score_simple.ipynb`는 `EXCLUDED=True` 행을 제외하고 `abs(z) >= 3`으로 계산하며 CP-Z4M은 제외함. 따라서 새 앱의 결과를 기존 노트북과 같은 결과로 소개하지 않음. 이번 기준과 원본 해시는 실행 기록에 따로 저장함.

원본 `LABEL=1`, 이번 Z-score 후보, 현장 확인 결과는 서로 다른 기록임. OP의 0과 작은 CP-Z4M 값도 그대로 계산함.

## 3D 동작 표시

구역 버튼은 화면 아래 한 줄로 표시한다. 한 번 누르면 해당 구역을 확대하고, 같은 구역을 다시 누르면 전체 보기로 돌아온다.

미확인 이상 후보가 있는 구역은 공정 위에 붉은 `확인 필요` 버튼을 표시하며 천천히 점멸한다. 해당 구역 외함·윤곽도 붉게 강조한다. 구역 선택이나 확대는 후보 확인 처리가 아니다. 그 구역의 모든 후보가 확인되면 위쪽 버튼과 점멸은 사라지지만 하단의 붉은 후보 표시와 개수는 남는다. 확인은 고장 해결이나 값의 복귀를 뜻하지 않는다. 동작 줄이기 설정에서는 점멸하지 않는다.

`frontend/tests/zone-preview.html`은 개발 서버에서만 여는 예시 상태 미리보기다. 실제 분석·알림·요청은 생성하지 않으며 일반 화면 빌드에는 포함하지 않는다.

언코일러·리코일러·롤러와 강판 이동은 공정 설명용 모션임. 실제 속도·가동 상태를 측정한 표시가 아님. 재생·정지할 수 있고 화면 동작 줄이기 설정을 따름.

## 공정 읽기와 알림 대응 가이드

메뉴의 `소둔로 공정 가이드`에서 소둔 목적·공정 흐름·구역 역할·가열 장비·센서 값·058/061·확인 연습을 읽는다. 이전·다음 버튼으로 한 단계씩 이동하며 이동 버튼은 본문 스크롤과 분리되어 항상 보인다. 종료하면 이전 LOT·시각을 복원한다.

알림 대응 가이드는 별도 기능이다. 이상 후보 목록 또는 펼친 알림의 `대응 가이드`를 눌렀을 때만 연다. 발생 위치·구간과 기록 확인 → 같은 구역 TC/OP 비교 → 운전 변화 검토 → 필요 시 점검 요청 → 결과·복귀 확인의 순서다. 현장의 승인 조작 매뉴얼을 대체하지 않으며, 목표값이나 정지 지시를 생성하지 않는다. 현재 LOT 전체 고정 통계 분석에는 이동 기준 Z 감소나 시작 고정 기준 복귀 판정이 없다는 점을 구분한다.

알림이 필요한 판단과 행동을 안내하도록 하는 [HSE 알림 관리 원칙](https://www.hse.gov.uk/humanfactors/topics/alarm-management.htm), 측정값 상태와 사람의 확인 상태를 구분하는 [Ignition 알림 상태](https://docs.inductiveautomation.com/docs/8.3/platform/alarming)를 참고한 앱의 확인 절차다.

## 값 표기와 창 조작

- CP-Z4는 사용자가 확인한 무차원 값으로 표시한다. CP-Z4M 같은 작은 수는 `1.152 e⁻¹⁰`처럼 계수와 회색 지수를 분리한다. 지수 표기는 물리 단위가 아니며 CP-Z4M의 물리 단위는 미확인이다. 실제 0과 결측은 구분한다.
- 구역 확대는 정면 중심으로 이동한다. 값창·그래프·가이드는 하단 구역 버튼을 가리지 않도록 배치한다.
- 그래프·모델·이상 후보·요청함 버튼은 같은 버튼을 다시 누르면 닫는다. 다른 창을 열면 기존 설명·메뉴·값창을 정리한다.
- 일반 창은 화면 밖의 짧은 클릭으로 닫힌다. 창 안의 읽기·스크롤·입력, 3D 회전 드래그는 바깥 클릭으로 처리하지 않는다. 공정 읽기 중 관련 3D 구역을 살펴볼 때는 설명을 유지한다.
- 팀 알림은 바깥 클릭으로 닫히지 않는다. 벨 버튼·닫기·알림 항목 선택으로 닫는다. 함께 열린 창은 팀 알림 아래로 배치한다.
- 점검 결과를 작성 중이거나 저장 중이면 요청함은 바깥 클릭으로 닫히지 않는다. 요청 작성 대화상자도 바깥 클릭으로 닫히지 않는다. 다른 화면으로 명시적으로 전환하더라도 요청함의 미제출 결과 입력은 현재 세션에 유지된다.
- 요청함은 상태별 건수·LOT/구역/채널/담당자 검색·다음 할 일을 표시한다. 요청 작성은 관측한 변화·함께 확인한 조건·점검할 내용으로 나누고 기존 서버 요청 형식으로 저장한다. 역할·권한은 변경하지 않는다.

`frontend/tests/ux-preview.html`은 사용성 검증 전용 예시다. 실제 앱 화면을 사용하지만 모든 API 요청은 예시 응답으로 대체한다. 직접 작성 요청·강종 연결·읽음·조치 완료는 해당 탭의 메모리에만 보관하며 다른 저장 요청은 거절한다. 실제 데이터·분석·알림·요청 기록을 만들지 않으며 일반 빌드에는 포함하지 않는다.

## 직접 요청과 화면 설정

요청함의 `새 점검 요청`에서 이상 후보 없이 LOT·채널·시간 구간과 관측한 변화·점검할 내용을 작성한다. 원자료 시각을 그대로 연결하며, 서버는 데이터 묶음·LOT·등록 채널·기간을 검증한다. 직접 작성 요청은 이상 후보나 분석 실행으로 생성하지 않는다. 후보 연결 요청과 직접 작성 요청은 동일한 접수·결과·검토 흐름을 사용한다. 재전송과 같은 대상·내용의 미종료 중복 요청은 새 기록과 알림을 추가하지 않는다.

계측 카드 표시·숨기기는 하단 Zone 선택 줄의 태그 버튼으로 조작한다. 위쪽 도구에는 홀로그램·금속 설비 표현 선택, 외함/내부 보기, 코일 색상과 화면 설정을 둔다. 홀로그램·금속 설비의 기본 표현은 유지하며, 선택한 부품만 기존 금속·고무·유리 등 원래 모형의 재질로 선명하게 표시한다. 주변 홀로그램은 기존 선택 강조처럼 옅어지고 붉은 이상 강조는 유지한다. 설정에서 중복 계측창 표시와 CP 위치 찾기를 제거했다. CP 장치 이동은 하단 CP 버튼을 사용한다.

팔레트 아이콘에서 `코일 온도 색상`을 켜고 끈다. 커서나 키보드 초점으로 버튼 설명을 읽을 수 있다. 켜면 내부를 열어 공정 안 강판을 보여주며 구역 TC에 따라 파랑·청록·노랑·주황·빨강으로 표시한다. 0~1000°C의 고정 설명용 색상 범례를 사용하며 범위 밖은 양끝 색으로 표시한다. 관측 없음은 회색이고 실제 0은 낮은 온도 색이다. OUT의 두 TC는 평균하지 않고 출측 1·2로 나눠 표시한다. 재생 시각이나 CSV 시연 값이 바뀌면 같은 색상 기준으로 갱신한다. 홀로그램·금속 표현의 조명과 관계없이 강판 색을 뚜렷하게 유지하며, 끄면 기존 강판 표현으로 돌아간다. 실제 강판 표면색·표면온도·경보 등급을 뜻하지 않는다. CP-Z4M의 `e⁻¹⁰`은 숫자의 크기를 표현하는 지수이며 물리 단위는 여전히 미확인이다.

전체 값은 공정 위 카드에 구역별로 묶어 표시하며 하단은 선택 버튼으로 유지한다. OUT 옆 CP는 CP 계측 바로가기이며 새 공정 구역이 아니다. 같은 구역을 다시 누르면 확대와 선택 정보가 함께 닫힌다.

하단 공정 선택·기록 재생 조작부는 커서가 멀어지면 옅어진다. 커서가 가까이 오거나 키보드 초점이 들어오면 즉시 선명해진다. 점검 후보 강조는 별도로 유지한다. 기존 3D의 형상·설비 구성·배치는 교체하지 않는다.

기록 재생과 설명용 세정·건조 동작은 독립된 스위치다. 세정·건조를 켜면 세정 구간 가까이 이동하고 내부를 열어 분사·브러시·건조 동작을 보여준다. 기록이 재생 중이어도 세정·건조만 끌 수 있다. 실제 강판 위치·설비 동작 추적을 뜻하지 않는다. 장비·부품을 선택하면 기존 카메라 구도와 설명용 부품 형상을 사용해 이동한다. 화면 설정의 부품 목록은 선택 후에도 열린 상태로 남아 다른 부품을 바로 누를 수 있다. 선택 해제는 강조와 부품 정보를 닫고, 설정의 X는 목록을 닫는다. O링 선택 시에는 기존에 벌려 보이던 연결판을 투명하게 표시해 검은 고무 링이 가려지지 않게 한다. 별도의 이름 표지나 O링 분해 배치를 추가하지 않는다.

상단은 `과거 기록 / 실시간 / 검색`으로 구성한다. 돋보기에서 자료 묶음을 고르고 LOT 번호·강종으로 검색해 해당 기록의 그래프를 연다. 실시간에서는 시연 CSV를 순서대로 수집하며 원자료 시각·LOT·강종·수집 진행을 표시한다. 실제 설비 연결과 구분하는 시연 안내를 유지한다. 과거 분석 후보와 시연 모델 이벤트는 별도 흐름으로 처리한다.

`고급 도구 → 그래픽 성능 확인`은 커서를 올린 동안만 표시한다. 커서를 떼거나 설정을 닫거나 다른 동작을 선택하면 성능 표시와 측정을 종료한다. 키보드로 해당 항목에 초점을 맞췄다가 벗어나도 같은 방식으로 동작한다.

## 간결한 조작부와 CP 비교

하단 구역 선택은 더 작게 아래로 배치하고 기록 재생 막대도 축소했다. 왼쪽 계측 정보는 하단 구역 선택의 실제 높이에 맞춰 바로 위에 배치한다. 전체 계측값·후보 개수 표시로 높이가 달라져도 버튼을 가리지 않는다. 작업 보기·전체 보기 버튼은 상단 화면 도구 가까이 배치한다.

OUT 옆 `CP`를 누르면 CP-Z4와 CP-Z4M을 같은 창에서 확인하고, 다시 누르면 닫는다. 두 채널 그래프도 함께 열 수 있다. CP-Z4M은 큰 숫자 `1.152`와 회색 지수 `e⁻¹⁰`을 분리한다. 실제 관측값을 바꾸거나 회색 지수를 물리 단위로 확정하지 않는다. 결측과 실제 0은 구분한다.

조회 코일의 강종이 있으면 제품군·특성을 자동 표시한다. 강종이 없는 자료는 `강종 연결`에서 확인된 실제 강종을 별도로 연결한다. 식별 색상과 설명 출처는 [강종·제품 설명](11-material-reference.md)에 있다.

결과는 `desktop/dist/`에 생성됨. 화면 빌드 뒤 API 서버를 다시 시작하면 `9017` 포트에서 화면과 API를 함께 제공함. 개발용 `5173` 서버 없이 exe를 사용할 수 있음.

Electron 창은 Node 접근을 끄고 격리된 화면으로 실행함. 서버 변경 시 기존 앱 세션을 지우며 원격 팀 서버는 HTTPS만 허용함. [Electron 보안 지침](https://www.electronjs.org/docs/latest/tutorial/security)

## 구역별 계측 카드와 커서 조회

설비 화면은 기존 3D 구조를 유지한다. 하단은 CLN-IN·Z1~Z9·OUT·CP 구역 선택 버튼이며 작은 수치를 나열하지 않는다. 태그 아이콘으로 공정 위 계측 카드를 표시하거나 숨긴다. 표시·숨기기는 하단 태그 버튼에서 전환한다. 화면 설정에는 같은 조작을 중복하지 않는다.

전체 보기에서는 같은 구역의 온도·제어출력을 하나의 카드로 묶는다. OUT의 두 온도 채널과 Z4의 CP 두 채널도 각각 함께 표시한다. 제공되지 않은 OP-Z9 값은 만들지 않는다. 카드는 대응 공정 위치와 연결선으로 이어지고, 이상 후보 계측은 붉은 카드·확인 필요 표시를 사용한다. 재생 시각이 도달한 현재 LOT의 미조치 후보를 표시하며, 되감아도 이미 발생한 미조치 후보는 유지한다. 실제 코일 위치·재적·용접점 추적은 신호가 없어 구현하지 않는다.

구역 버튼을 누르면 정면에서 주변 설비가 남는 거리로 확대한다. 확대 시 선택 구역과 앞뒤 한 구역의 계측 카드만 남긴다. 미조치가 없는 구역은 같은 버튼을 다시 누르면 전체 보기로 돌아오고, 미조치가 있는 구역은 해당 계측의 상세로 연결한다. 구역 버튼·계측 카드·3D 공정에 커서를 올리거나 키보드 초점을 맞추면 왼쪽에 계측 정보를 미리 표시하고, 벗어나면 자동으로 닫는다. 클릭한 계측은 다른 구역에 커서를 올려도 유지한다. X로 닫은 직후 같은 구역의 움직임만으로 다시 열리지 않으며, 구역에서 벗어났다 다시 진입하면 새 조회를 할 수 있다. 커서 조회는 카메라와 그래프 채널 선택을 바꾸지 않는다. 설정·공정 읽기·요청 작성 중에는 커서 조회가 끼어들지 않는다.

하단 CP 버튼은 다른 구역 버튼과 같은 크기로 표시하며 한 번 누르면 CP-Z4·CP-Z4M을 함께 열고 다시 누르면 닫는다. CP-Z4는 무차원으로 표시하며 CP-Z4M은 계수와 회색 `e⁻¹⁰` 지수를 구분한다. 이 지수는 측정값의 크기 표기이며 물리 단위를 뜻하지 않는다.

전체 계측 카드는 각 Zone의 공정 위치 주변에 둔다. 회전할 때 해당 Zone과 함께 이동하며 기존에 떨어진 방향·간격을 최대한 유지한다. 커서 조회·경고 우선순위 변경으로 자리를 바꾸지 않으며, 창·다른 카드와 겹치면 가까운 빈자리로 부드럽게 조정한다. 화면 전체의 표 형태로 다시 나열하지 않는다. 카드 크기는 148×94px이며 계측값은 18px로 표시한다. 공정이 화면 밖으로 벗어나면 해당 카드와 연결선도 숨긴다. 연결선은 카드 아래에 그리며 선택하거나 커서를 올린 항목을 선명하게 표시한다.

하단 CP를 열면 저장된 CP-Z4 표시 장치를 중심으로 시점이 이동하면서 CP-Z4·CP-Z4M 값을 함께 표시한다. 다시 누르면 값창을 닫고 전체 보기로 돌아간다. CP 연결선도 같은 저장 좌표를 사용한다. 이는 기존 모형의 표시 위치이며 실제 설치 좌표·부품과의 연결을 새로 확정한 것은 아니다. CP 값창만 커서로 미리 본 상태에서 버튼을 눌러도 이동·선택을 실행한다.

Z4 온도·제어출력과 CP는 같은 물리적 공정에 속하지만 알림 개수·붉은 계측 카드·하단 버튼·상세 목록을 분리한다. CP에서만 후보가 발생하면 CP만 알림으로 표시하며 Z4 온도·제어출력 카드는 일반 상태를 유지한다. 어느 쪽의 후보라도 남아 있으면 물리적 Z4 설비의 붉은 강조는 유지한다. `CP 계측`과 CP 이상 상세의 정보 아이콘에서 Carbon Potential의 뜻, 두 채널의 표시 방법과 제조사 기술자료를 확인할 수 있다. 현장 환산식·관리 기준을 새로 가정하지 않는다.

## 미조치 유지와 구역 상세

### 실시간 수신과 이전 기록 조회

CSV 시연의 수신은 1초마다 1행으로 고정한다. `수신 중`·행 수·최신 관측 시각은 실제로 도착한 행을 기준으로 갱신하며, 파일 끝까지 도착한 경우에만 `수신 완료`로 표시한다. 전체 파일 끝 시각·진행 막대·수신 배속·처음부터 버튼은 실시간 조작부에서 제외한다. CSV 원자료 시각을 실제 설비 연결 시각으로 바꾸어 소개하지 않는다.

`30초 전`은 수신을 멈추지 않고 이미 도착한 기록을 조회한다. 이전 기록을 재생할 때만 1·2·4·8·16배속을 선택할 수 있다. 움직이는 현재 수신 지점에 닿으면 배속을 해제하고 자동으로 1배속 실시간 화면으로 복귀한다. `현재로`도 같은 동작이며, 수신이 끝난 경우에는 마지막 수신값으로 돌아간다. 3D 계측과 그래프의 조회 시각은 맞추되 예측 모델은 계속 최신 수신 지점을 기준으로 계산한다.

실시간 이전 기록에도 ←/→ 5초, Shift+←/→ 30초 이동을 제공한다. 재생 중에 이동하면 이전 기록의 재생·배속을 유지하며, 현재 수신 지점에 닿으면 1배속 실시간으로 돌아간다. 실시간을 보고 있을 때 ←는 5초 전 기록을 열고, 아직 받지 않은 미래로는 이동하지 않는다. 이전 기록 조작부의 일반 버튼에 초점이 있어도 방향키 이동을 사용할 수 있다. 슬라이더·배속 선택창·입력창·3D 조작·대화상자의 키보드 조작은 유지한다. Space 재생·정지는 이전 기록 조회에만 적용하며 수신을 멈추지 않는다.

실시간 그래프도 클릭으로 관측 시각을 고르고, 드래그한 구간을 확대하거나 ± 버튼으로 범위를 조절할 수 있다. 조회·확대의 끝은 최신 수신 지점을 넘지 않는다. 이상 알림을 누르면 감지 구역·기간·판정 기준·분류 점수와 구간 직전 값·감지 구간 내 관측 범위를 먼저 표시한다. 감지 구간은 그래프의 붉은 영역으로, 비교값과 가장 차이 나는 관측은 점으로 표시한다. RandomForest의 구역 분류 점수와 함께 관측된 변화는 고장 확률이나 원인 채널 확정을 뜻하지 않는다. 원본 CSV의 LABEL=1 표시는 모델 감지 구간과 구분한다.

과거 자료의 경보 문구는 `이상 징후 감지`이며 가장 최근에 발생한 채널·발생 시각을 바로 연다. 재생 시각이 후보 시작에 도달하면 별도 갱신 주기를 기다리지 않고 표시한다. 고장 확정이나 미래 예측을 뜻하지 않는다. CSV 시연의 모델 이벤트·그래프·현장 요청 연결은 최신 main 구현을 유지한다. 과거 LOT 전체를 이용한 Z-score 분석은 실시간 탐지 모델로 표시하지 않는다.

점검 요청·저장된 분석·채널 그래프를 포함한 오른쪽 창의 기본 너비는 화면의 약 34%(420~900px)이며 좁은 화면에서는 가용 너비에 맞춘다. 창 크기를 바꿔도 그래프의 축 숫자와 관측 시각은 실제 14px 크기를 유지한다. 좁은 그래프는 시간 눈금을 세 개로 줄여 겹침을 피하고, CP-Z4M은 e⁻¹⁰ 배율을 따로 표시한다. 본문·범례·관측값도 모니터링 시 읽을 수 있도록 확대한다.

기록 재생 단축키는 최신 main 구현을 유지한다. 입력창·버튼·3D 조작 등 다른 조작에 초점이 없을 때 Space는 재생·정지, ←/→는 앞뒤 5초, Shift+←/→는 앞뒤 30초 이동한다. LOT 양끝에서 멈추며 재생 중이면 재생 상태를 유지한다. 재생 위치 슬라이더와 속도 선택창 등 자체 방향키 조작은 가로채지 않는다.

메뉴의 소둔로 공정 가이드는 공정 흐름·TC/OP/CP·정비 구분·설명용 연습·장치 사전으로 나눈다. 존별 역할과 확인할 값, 설명용 정지/재가동 추세, 선택형 연습과 해설을 제공한다. 정비 기록이 확인된 변화와 추가 점검이 필요한 상황을 구분하며 그래프 모양만으로 정상 처리하거나 알림에서 자동 제외하지 않는다. 학습 진행·답변은 실제 분석이나 점검 요청으로 저장하지 않는다. 버너·래디언트 튜브는 장치 사전에서 따로 읽는다.

오른쪽에는 현재 LOT에서 재생 시각이 도달한 미조치 후보를 발생 순서대로 표시한다. 설정·상세 창을 열면 배너가 조작부를 덮지 않도록 위치를 조절한다. 처음부터 미래 후보를 모두 표시하지 않으며, 같은 LOT에서 되감아도 이미 발생한 후보는 조치 완료 전까지 유지한다. LOT을 바꾸면 새 LOT의 재생 시각을 기준으로 표시 범위를 다시 잡는다. 읽음 표시, LOT 전환, 재생 구간 이동, 추가 분석 끄기는 저장된 후보의 조치 완료가 아니다. 이 목록은 과거 자료의 확인 과제이며 현재 설비가 이상 상태라는 뜻은 아니다. 다른 LOT이나 전체 저장 후보는 해당 LOT의 저장된 분석에서 확인한다.

구역 보기·붉은 구역 카드·해당 구역 버튼을 누르면 주변 설비가 남는 거리로 이동하고 오른쪽에 구역·채널·후보 구간·최대 이탈값과 관측값 그래프를 함께 연다. 그래프 점선은 저장된 LOT 평균 ±3σ이며 운전 정상 범위가 아니다. 후보 구간·앞뒤 5분·LOT 전체로 범위를 바꿀 수 있다. 세로축은 관측값과 기준선의 변화 폭에 맞추고, 화면에서 눈금을 일정한 간격으로 표시해 작은 온도 변화에서도 숫자가 겹치지 않도록 한다. CP-Z4M의 축은 e⁻¹⁰ 배율을 따로 표시한다.

조치 내용을 기록하거나 연결된 점검 요청의 결과를 최종 확인해야 미조치 강조가 종료된다. 요청이 진행 중이면 직접 종료를 막고 기존 점검 결과 절차로 연결한다. 완료 기록은 저장된 분석에서 다시 열 수 있고 재점검을 요청해도 이전 조치 이력을 보존한다. 기존에 최종 확인된 요청은 저장된 실제 결과·확인자·시각을 새 완료 기록에 연결한다. 원본 관측값은 바꾸지 않는다.

분석 모델·테마·그래프를 상단 중앙에, 저장된 분석·팀 점검 요청·팀 알림을 오른쪽에 배치한다. 팀 알림 창도 오른쪽 끝에 맞춘다. 공정 가이드는 메뉴의 소둔로 공정 가이드에서 연다. 아이콘은 커서 또는 키보드 초점으로 설명한다. 기본 카메라는 양쪽 코일이 보이는 정면 구도다. 세정·Z1·Z2·Z7~Z9·OUT은 낮은 외함의 모형 높이에 맞춰 가열 구간보다 가까이 확대한다. 계측 카드는 확대 여부와 관계없이 배경과 글자를 선명하게 유지한다. 하단 구역·재생 바는 커서가 멀어지면 옅어진다. 두 바에서 72px 안으로 접근하거나 키보드 초점을 두면 선명해진다. 터치 화면에서는 선명하게 유지한다. 작업 보기는 선택 구역을 보는 기능이며 코일 추적을 하지 않는다.

상단에서 여는 그래프·이상 후보·모델 선택·팀 확인 요청과 구역 상세·대응 가이드는 왼쪽·아래 가장자리 또는 왼쪽 아래 모서리를 끌어 크기를 조절한다. 방향키도 사용할 수 있으며 Shift는 더 큰 간격으로 조절하고 Home 또는 상단 복원 버튼은 기본 크기로 되돌린다. 창별 크기는 닫았다 다시 열어도 현재 페이지 세션 동안 유지되며, 화면 밖이나 하단 구역 선택을 덮지 않도록 조절 범위를 제한한다. 구역 이상 상세의 `뒤로`는 이전 창의 검색·펼침·스크롤·조절한 크기를 유지하여 돌아간다. X는 상세 창을 닫는다.

서버 변경에는 `0005_candidate_resolution` 마이그레이션이 포함된다. 배포 전 백업을 확보하고 `python backend/manage.py migrate --noinput`으로 적용한다. 조치 완료 상태·작성자·시각·내용과 조치 이력을 추가하며, 기존에 최종 확인된 점검 요청의 실제 결과를 연결한다. 진행 중인 재점검은 미조치 상태를 유지한다. 백업·복원 절차는 [팀 서버 안내](11-team-server.md)를 따른다.

예시 화면은 `frontend/tests/ux-preview.html`이다. 프런트엔드 개발 서버에서 `/tests/ux-preview.html`을 열면 예시 LOT·Z3 후보를 볼 수 있다. `?alarms=cp`, `?alarms=z4`, `?alarms=both`는 CP만·Z4 온도/출력만·양쪽 발생 예시이며, 재생 시각을 후보 시작 이후로 이동해 확인한다. 이 화면은 API 호출을 예시 응답으로 바꾸며 실제 분석·알림·요청 기록을 만들지 않는다. LOT별 제품 정보 근거와 원자료를 보존하는 강종 연결 절차는 [코일 강종과 제품 설명](11-material-reference.md)을 참조한다.
